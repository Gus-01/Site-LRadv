# Site — Lourdes Amabilia Reis Campos

Versão programada do site institucional, reconstruída em HTML, CSS e JavaScript a partir do layout/identidade visual fornecidos.

## Como abrir
1. Extraia o ZIP.
2. Abra `index.html` no navegador.
3. Para publicar, envie a pasta inteira para uma hospedagem estática (Netlify, Vercel, GitHub Pages, Hostinger etc.).

## Arquivos
- `index.html` — estrutura e conteúdo.
- `style.css` — identidade visual, responsividade e animações.
- `script.js` — menu mobile, efeitos de entrada e navegação.
- `assets/` — imagens fornecidas no pacote original.
